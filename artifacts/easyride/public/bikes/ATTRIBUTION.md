# Photo credits — `/bikes/`

Every photo in this folder is downloaded and stored locally (nothing is hotlinked at
runtime). Each entry lists the original source, the author and the licence so the
project stays attributable.

All images were resized to a maximum width of 800 px and re-encoded as JPEG so the
rider app stays fast.

## Accuracy note

The photos are representative of the **model family**, not always the exact trim
shown on the dashboard (for example the "Cannondale CAAD13" entry uses a CAAD 5
rebuild and the "Schwinn Wayfarer" entry uses a 1987 Schwinn cruiser). They are
matched to the catalogue as the closest openly licensed photograph available.
